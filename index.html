    How it works

    Type numbers into A and B (or use the fill buttons), then pick an operation. Addition and subtraction need the same size; multiplication needs A columns = B rows. Determinant, inverse and trace need a square A. Everything runs in your browser — no data ever leaves this page.

    Educational tool. Results are rounded to 6 decimal places. 100% offline — no accounts, no network requests.
